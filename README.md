# 3D Printable designs for Homey Portal

To enable an ecosystem of customized mounts for [Homey Portal](https://homey.app/portal) this repository holds technical drawings and 3D designs for Homey Portal's mounting system.

Please feel free to use & modify them for your own needs, and share them with others. Smart home is better together!
